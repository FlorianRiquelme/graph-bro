# graph-bro

Graph-based **workflow orchestration** for coding agents — nodes, conditional edges, loops,
joins, parallel fan-out, and human checkpoints. This is about orchestrating *work* (control
flow across agent runs), not graph memory, knowledge graphs, or GraphRAG.

## Status

Early. Currently a research/reference stage — see [`docs/research/graph-orchestration-landscape.md`](docs/research/graph-orchestration-landscape.md)
for the landscape survey and a dependency-ordered build plan.
